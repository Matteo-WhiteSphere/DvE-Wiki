Add a staff account

Staff username: creates the login Role.Name (e.g. Editor.Rapha) with a temporary password that you pass on; it must be changed at the first login.
Google: the person signs in with that Google account and gets the role automatically.
E-mail + password: an account is created and the person receives an e-mail to choose their own password.

Create several staff accounts

One username per line, written as Role.Name (Owner / Admin / Editor). Accounts that already exist are skipped. Each account gets a temporary password, shown only once below, that must be changed at the first login.

Users

owner manages admins (set only from the Firebase console or tools/accounts.mjs) · admin manages editors, deletes pages · editor creates and edits pages · user can only read · disabled blocked

Forgotten password of a staff username: an owner runs node tools/accounts.mjs reset Editor.Name (see STAFF_SETUP.md). Changing the role here does not rename the login.
